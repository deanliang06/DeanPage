01 / NATIVE SYSTEMS · WINDOWS

TinyShell

A lightweight native Windows shell written in C, built directly on Win32 and GDI. Process creation, pipes, output buffering, and command history — from the API up.

A smaller systems footprint. Under 1.5 MiB of shell-process private working set in two documented local workloads, roughly 96% below Windows PowerShell 5.1 in those tests.

  • C
  • Win32
  • Processes & pipes
  • Memory management
