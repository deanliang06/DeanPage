# Local asset sources

- Three.js 0.180.0: https://registry.npmjs.org/three/-/three-0.180.0.tgz (MIT license in vendor/three/LICENSE).
- VT323: https://github.com/google/fonts/tree/main/ofl/vt323 (OFL license in fonts/OFL.txt).
- Docker, AWS, Git, GitHub, Linux, GitHub Actions (CI/CD), PostgreSQL icons: https://github.com/devicons/devicon/tree/v2.17.0/icons (Devicon MIT license).
- AI agents: https://github.com/lucide-icons/lucide/blob/main/icons/bot.svg (Lucide ISC license).

All icons and the font are served locally. The robot icon represents AI agents, and GitHub Actions represents CI/CD. Accessible names communicate the skill, without visible labels.
